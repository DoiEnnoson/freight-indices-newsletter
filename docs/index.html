Weekly Freight Indices Newsletter

WCI, SCFI & IACI jeden Freitag per E-Mail

Was du bekommst

Einmal pro Woche, freitags, eine E-Mail mit den aktuellen Werten der wichtigsten Container-Frachtindizes: Drewry World Container Index (WCI), Shanghai Containerized Freight Index (SCFI) und Drewry Intra-Asia Container Index (IACI). Dazu Charts zur Entwicklung und eine Tabelle mit Wochen- und Vorjahresveränderung. Der Newsletter ist kostenlos und auf Englisch.

So meldest du dich an

  1. Formular öffnen, E-Mail-Adresse eintragen und die Einwilligung bestätigen.
  2. Innerhalb eines Tages kommt eine Bestätigungsmail. Antworte einfach darauf.
  3. Ab dem nächsten Freitag erhältst du den Newsletter.
Zum Anmeldeformular

Das Formular wird von Google Forms bereitgestellt. Details im Datenschutzhinweis.

Abmelden

Jeder Newsletter enthält unten einen Link „Unsubscribe“. Alternativ eine E-Mail mit dem Betreff Unsubscribe an doisnews@gmail.com schicken.
